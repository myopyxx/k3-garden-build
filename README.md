# Дневники Алисы

Маленькая браузерная игра-подарок: два котика, одиннадцать уровней (два из них ивентовые), гардероб, лавка, альбом и награды. Игра лежит в одном `index.html`, фото встроены в него. Чтобы играть, сборка, сервер и зависимости не нужны. Вторая игра, «Ночная арена», лежит в `arena/`.

## Что в репозитории

| Файл | Зачем |
|---|---|
| `index.html` | вся игра: разметка, стили, код, звук, фото. Собранный файл, руками не правится |
| `arena/index.html` | «Ночная арена»: отдельная игра с теми же котиками. Тоже собранный файл |
| `src/` | исходники обеих игр, сборка и проверки. Как с ними работать, написано в `src/README.md` |
| `icon-180.png` | иконка для экрана «Домой» на iPhone |
| `icon-192.png`, `icon-512.png` | иконки для манифеста |
| `manifest.webmanifest` | запуск во весь экран, как приложение |
| `robots.txt` | просит поисковики не индексировать сайт |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Как открыть на iPhone

1. Открой ссылку в Safari.
2. Нажми «Поделиться» → **«На экран „Домой“»**. Появится иконка с Алисой, и игра будет запускаться во весь экран, как приложение.
3. Для звука выключи беззвучный режим переключателем сбоку.

Прогресс хранится в самом телефоне. Если открыть игру с иконки на экране «Домой», а потом в Safari, это будут два отдельных сохранения.

## Что поменять

Тексты, цены, фразы котиков, окрас и песня задаются в блоке `CONFIG` в начале скрипта в `src/main/diana.src.html`. Фото лежат в `src/main/photos.js`. После правки игру нужно пересобрать: `python3 src/main/build.py`. Правки прямо в `index.html` следующая сборка сотрёт.
