# Дневники Алисы

Маленькая браузерная игра-подарок: два котика, девять уровней, лавка, альбом и награды. Весь сайт лежит в одном `index.html`, фото встроены в него. Сборка, сервер и зависимости не нужны.

## Что в репозитории

| Файл | Зачем |
|---|---|
| `index.html` | вся игра: разметка, стили, код, звук, фото |
| `icon-180.png` | иконка для экрана «Домой» на iPhone |
| `icon-192.png`, `icon-512.png` | иконки для манифеста |
| `manifest.webmanifest` | запуск во весь экран, как приложение |
| `robots.txt` | просит поисковики не индексировать сайт |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

## Как выложить на GitHub Pages

1. На github.com нажми **New repository**, придумай неочевидное имя (например, `a7k-diaries`) и создай репозиторий.
2. Нажми **uploading an existing file** и перетащи все файлы из этой папки, включая `.nojekyll`. Затем **Commit changes**.
3. Открой **Settings → Pages**. В блоке **Build and deployment** выбери **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через одну–две минуты сайт будет доступен по адресу `https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Приватность

На бесплатном аккаунте GitHub Pages работает только с **публичными** репозиториями. Это значит, что любой, кто найдёт репозиторий, увидит код и фото внутри `index.html`. `robots.txt` просит поисковики не индексировать сам сайт, но репозиторий на github.com остаётся открытым. Для Pages из приватного репозитория нужен платный GitHub Pro.

## Как открыть на iPhone

1. Открой ссылку в Safari.
2. Нажми «Поделиться» → **«На экран „Домой“»**. Появится иконка с Алисой, и игра будет запускаться во весь экран, как приложение.
3. Для звука выключи беззвучный режим переключателем сбоку.

Прогресс хранится в самом телефоне. Если открыть игру с иконки на экране «Домой», а потом в Safari, это будут два отдельных сохранения.

## Что поменять

Тексты, цены, фразы котиков, окрас, песня и фото задаются в блоке `CONFIG` в начале скрипта в `index.html`.
