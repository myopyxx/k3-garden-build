# Исходники

Сайт собирается из этой папки. Готовые файлы в корне репозитория (`index.html`, `arena/index.html`) руками не правятся: следующая сборка их перезапишет.

| Папка | Что это | Сборка | Куда кладёт результат |
|---|---|---|---|
| `main/` | основная игра «Дневники Алисы» | `python3 src/main/build.py` | `index.html` |
| `arena/` | «Ночная арена» | `python3 src/arena/build.py` | `arena/index.html` |
| `redesign/` | черновик нового оформления, на сайте его нет | `python3 src/redesign/build.py` | `src/redesign/sample.html` |
| `tests/` | проверки в браузере | `node src/tests/<имя>.js` | снимки рядом с тестом |

Нужны Python 3, Node и Playwright с Chromium. Любой сборке можно передать путь, тогда результат уйдёт туда, а сайт не изменится: `python3 src/main/build.py /tmp/проба.html`.

Отправка в ветку `main` сразу обновляет сайт. Сначала сборка и проверки, потом отправка.

## main: основная игра

- `diana.src.html` — вся игра одним файлом, только без фотографий.
- `photos.js` — фотографии в base64. Сборка вставляет их на место метки `/*PHOTO_DATA*/`.
- `lint.py` — ищет дубли `@keyframes`, функций, констант и `id`. Дубль молча перекрывает первое определение, поэтому запускать перед каждой сборкой.
- `build.py` — проверяет синтаксис скрипта и только потом пишет `index.html`.

Сохранение игрока лежит в `localStorage` под ключом `alisa-diaries-v3`. Формат менять нельзя без переноса старых данных.

## arena: «Ночная арена»

`shell.html` — разметка и стили. Код склеивается в таком порядке: `core.js` (звук, сохранение, общие функции), `maps.js` (карты), `game.js` (бойцы, столкновения, бой, ИИ), `modes.js` (три режима), `render.js` (рисование), `main.js` (управление, меню, цикл кадра).

Адрес понимает параметры для отладки: `?auto=1` (за игрока играет бот), `?mode=gems|surv|waves` (сразу в режим), `?wave=N` (начать с волны N). Сохранение: ключ `night-arena-v1`.

## redesign: черновик нового оформления

- `sample.src.html` — образец: заставка, главный экран, главы.
- `render.html` — шейдер, который рисует объёмных котиков и кольцо.
- `render-sprites.js` — прогоняет шейдер и сохраняет слои в `sprites/`: тело, хвост и голова в трёх состояниях глаз для каждой кошки. Занимает около двух минут.
- `sprites/` — готовые слои. Сборка вшивает их в `sample.html`.

Картинки пересоздаются побайтно одинаковыми, поэтому после правки шейдера в коммит попадут только реально изменившиеся слои.

## tests: проверки

Все тесты открывают собранные файлы из корня репозитория, поэтому сначала сборка. Тест печатает `ERRORS none`, если в консоли страницы не было ошибок.

| Файл | Что проверяет |
|---|---|
| `helper.js` | общий запуск страницы для тестов основной игры. Запущенный сам по себе, снимает главные экраны и листы. Аргументы: ширина и высота |
| `main-petting.js` | главная: тап, свайп по шерсти, пружина, сверхмурчание, бонус нарядов |
| `main-perks.js` | перки гардероба на уровнях и подсказки перед стартом |
| `main-music-stems.js` | громкость шкатулки с нарядами и без: ловит перегруз и тишину, слух не заменяет |
| `main-album-scratch.js` | проявка нового снимка пальцем, старые сохранения, наклон снимка в просмотре |
| `main-levels.js` | бот проходит уровни 2, 3, 4 и 6. Аргументы: список уровней и режим `perfect` или `human` |
| `main-sizes.js` | уровни на маленьком и большом экране |
| `main-awards-flip.js` | переворот карточки в наградах |
| `arena-bot.js` | бот играет режимы арены до итога. Аргументы: режимы через запятую, ширина, высота |
| `arena-controls.js` | меню, обучение, джойстики, супер, пауза |
| `arena-details.js` | прицел, пустой магазин, нокаут, кнопка супера |
| `arena-corner-respawn.js` | кошка не застревает на углу стены; отсчёт после нокаута |
| `arena-perf.js` | частота кадров и число долгих кадров |
| `arena-reduced-motion.js` | арена с выключенной анимацией в настройках системы |
| `redesign-shots.js` | снимки образца. Аргументы: ширина, высота, метка |

Тесты имитируют палец мышью. Два пальца одновременно, звук и вибрацию они не проверяют: это только на настоящем iPhone.
